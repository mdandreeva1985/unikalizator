# Уникализатор

Веб-приложение, которое делает технически разные копии ролика прямо на устройстве (iPhone, Android, компьютер). Видео никуда не отправляется, после установки приложение работает без интернета.

Откройте ссылку в Safari или Chrome, затем «Поделиться» → «На экран “Домой”».

Использует библиотеку [Mediabunny](https://github.com/Vanilagy/mediabunny) (лицензия MPL-2.0, см. `vendor/`).
